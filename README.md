# yogapp-audio-en-au-natasha

Unzipped en-au-natasha voice clips for SynthYoga Cast receivers, served at
https://syntithenai.github.io/yogapp-audio-en-au-natasha/v1/

Published by `apps/yoga/scripts/publish-voice-files.sh` in the yogapp repo.
The phone app downloads the same clips as a zip from
https://syntithenai.github.io/yogapp-audio-en-au-natasha/v1/en-au-natasha.zip
